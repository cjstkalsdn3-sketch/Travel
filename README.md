# 우리 여행

둘이 함께 쓰는 해외여행 일정·예산 앱 (모바일 우선 웹앱).

## 기능
- 일정: 날짜별 타임라인, 장소 사이 이동 시간과 빠듯한 일정 경고, 지도 링크, 예약번호 연결
- 가볼 곳: 링크로 저장해두고 일정에 넣기
- 예산: 다중 통화 지출 기록(원화 환산), 카드/트래블카드/현금, 남은 현금, 둘 사이 정산
- 준비물: 담당자 지정 체크리스트
- 예약·정보: 예약번호·바우처 보관, 나라별 시차·전압·팁·입국·긴급번호

## 개발
```bash
npm install
npm run dev
```

데이터는 지금 브라우저(localStorage)에 저장된다. `src/lib/store.ts`의 `load`/`persist`를 Supabase로 바꾸는 것이 다음 단계.
